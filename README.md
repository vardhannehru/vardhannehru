## Projects

### [VIMAN](https://github.com/vardhannehru/viman-website)

**Next.js 15 · React 19 · TypeScript · Three.js · GSAP · Tailwind**

A site for the DGCA pilot pathway, built as one continuous flight. An aircraft
takes off, climbs, cruises and lands as you scroll — rendered live in WebGL in
the browser, driven by a single scroll value rather than a stack of separate
animations. Runs on a capability probe that drops quality on weaker devices,
suspends the render loop when the scene leaves the viewport, and turns the whole
thing off for `prefers-reduced-motion`.

### [Sri Venkatarama Farms](https://github.com/vardhannehru/sri-venkatarama-farms)

**Vue 3 · TypeScript · Node.js · PostgreSQL · Docker**

A management system for a working quail farm: billing and POS, product and stock
management, daily bird targets, and separate admin and salesman access levels.
Runs on a JSON store locally and PostgreSQL in production, containerised for
deployment.

### [Future Spark International School](https://github.com/vardhannehru/FutureSpark)

**React · Vite · JavaScript**

Website for a school, built freelance to a stakeholder brief and maintained
after handover — content updates, layout fixes, and cross-device testing.

### [EV Cost Prediction](https://github.com/vardhannehru/-EV-Cost-Prediction)

**Python · regression modelling**

A model estimating electric vehicle cost from battery and specification data.
Data cleaning, feature selection, and evaluation of the fit.
